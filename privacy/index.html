Privacy Policy

Last updated October 12, 2026

Vellix stores only what it needs to run its features: Discord IDs, usernames, levels, coin balances, warnings, and server settings. It does not sell data and does not store the text of your messages.

1. Data Vellix stores

DataWhat it includesWhy

Vellix does not collect your email, IP address, real name, payment information, or direct messages.

2. Message content

Vellix reads messages as they are sent but does not save their text in its database.

  • Leveling only notes that you sent a message, so it can award XP.
  • AutoMod, when a server turns it on, checks messages for spam, links, invites, mass mentions, and blocked words. Recent message times are kept in memory for a few seconds to detect spam, then discarded.
  • Server logs and mod-logs, when a server turns them on, post copies of edited or deleted messages, and messages removed by AutoMod, into a channel in that same server. Those copies live in Discord, are controlled by that server's staff, and are not stored by Vellix.

3. How data is used and shared

Data is used only to run Vellix's features. We never sell it, rent it, or use it for advertising.

  • Global leaderboards show your username, level, and coin total to users in every server that has Vellix. You can hide your name (section 5).
  • Server leaderboards show members' display names and levels to that server.
  • Server staff can see warnings and settings for their own server only.
  • Legal requests. We may share data if the law requires it, or to protect users or Vellix from harm.

Vellix runs through Discord, so Discord also processes this data under the Discord Privacy Policy.

4. Storage, security, and retention

Vellix's data is kept in a private database on a computer or server controlled by the developer. Only the developer can access it, and the bot's login token is kept private.

  • Levels and coins are kept while you use Vellix, so your progress is still there when you come back.
  • Warnings are kept until server staff delete them with /delwarn or /clearwarnings, or until you ask us to delete them.
  • Server settings are kept after Vellix leaves a server, so they return if it is added again. Server owners can ask us to delete them.

No system is perfectly secure. If a data breach affecting users ever happens, we will announce it in the support server.

5. Your choices and rights

  • Hide your name on global leaderboards at any time with /lbprivacy. You will show as "Anonymous" instead.
  • Ask for a copy of the data Vellix stores about you.
  • Ask for deletion of your data. Deleting it resets your levels, XP, and coins permanently. Warnings may be kept if a server needs them for moderation, but you can ask that server's staff to remove them.
  • Server owners can turn features off, or remove Vellix and ask us to delete their server's settings.

To make a request, contact us through the support server (section 6). We aim to respond within 30 days.

6. Children, changes, and contact

Children. Vellix is only for people who meet Discord's minimum age in their country. We do not knowingly collect data from anyone younger. If you believe a child's data is stored, contact us and we will delete it.

Changes. We may update this policy when Vellix changes, for example when a website dashboard launches. We will update the "Last updated" date and announce major changes in the support server.

Contact. For questions or data requests, join the Vellix support server. See also the Vellix Terms of Service.
