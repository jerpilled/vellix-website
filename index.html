Two levels, one profile

Every message earns XP twice: once for the server you're in, and once for a global level that follows you everywhere Vellix is.

  • Server staff set role rewards, XP rates, and no-XP channels.
  • Global XP can't be edited by any server, and joining more servers doesn't earn it faster.
  • Every new global level pays out coins.
  • Prefer to stay off the global leaderboard? /lbprivacy hides your name.

One wallet, every server

Add Vellix in three steps

  1. Click Add to Discord and choose your server.

  2. In Server Settings, drag the Vellix role above the roles you want it to manage.

  3. Type /help to see every command by category.
